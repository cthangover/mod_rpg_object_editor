# RPG 对象编辑器 — 用表单编辑 RPG 世界的对象

RPG 对象编辑器用于编辑 RPG 世界中的对象：地面材质、墙壁和栅栏段、网格上的道具以及角色。每个对象都有图片、网格上的占地范围、锚点（对象站立的点）、状态、变体、光源、可选的路线以及可选的互动。表单旁边的预览用游戏自己的渲染器，按**俯视**和**等轴测**两种投影绘制对象。**保存**会写入模组文件，游戏立即使用该对象。日常工作无需原始 JSON；**其他字段**框留给高级用户。

从工具栏的工具箱（锤子图标）打开，名称为**RPG 对象**。

## 编辑器中的对象

左侧列表显示所选模组的对象，每个都有缩略图。右侧表单编辑所选对象。下面是 RPG Plus 的补给桶：

![RPG 对象窗口，位于 rpg_plus_game：对象列表中选中补给桶，表单显示 Id rpg_plus/container/supply_barrel、Form sprite、每种语言的名称文本、Category container 以及 Extends village_pack/container/barrel。](assets/object-own-form.jpg)

工具栏有**保存**（Ctrl+S）、**新建**（Ctrl+N）、**复制**（Ctrl+D）、**删除**、**撤销**和**重做**（Ctrl+Z、Ctrl+Y）。新对象是一个尚无图片的精灵，其 id 以模组名加 `new_object` 开头。

## 表单

字段取决于表单顶部选择的 **Form**：

- **Surface**（表面）— 地面材质：图片（地图补丁尺寸的正方形）、**与相邻材质融合**及融合宽度、**水**，以及其变体的图片。
- **Segment**（分段）— 一个墙或栅栏格：图片、**Connect**（相同键的分段相互连接）、**Along**（等轴测中竖直平面的方向）、以格为单位的**高度**，以及其变体的图片。
- **Sprite**（精灵）— 网格上的对象：它的**部件**（图片）、**占地范围**（宽高以格计及遮罩）、**锚点**、标志、互动、状态、变体、光源和路线。
- **Actor**（角色）— 占一格的角色：其 **Charset**（行走图）、**Facing**、**Column**、互动、状态、变体、光源和路线。

所有表单都有 **Id**、**Name**（模组每种语言的文本，保存在语言文件中）、**Category**（调色板用的标签，如 `container`、`vegetation`、`building`）以及 **Extends**（父对象的 id）。

## 图片与 PNG 导入

**导入 PNG...**（在*图片*块中）把你磁盘上的 PNG 复制到被编辑模组的 `rpg_images/<分类>/`，并将其设为对象的图片：第一个部件、表面或分段。不会生成任何内容。文件会先被检查：

- 不是 PNG 的文件会被拒绝，且不复制任何内容；
- 精灵部件的每边应为地图格子的整数倍（默认格子尺寸 32 像素）；其他尺寸会导入，但会给出警告，说明部件会被切掉或留下缝隙；
- 表面应为地图补丁尺寸（默认 128 像素）的正方形；其他尺寸会导入并给出警告；
- 若 `rpg_images/<分类>/` 中已存在同名文件，将被拒绝：请选择另一个文件名。

**部件**和**变体**的图片也可以用 **…** 选择器从该组中选取。

## 部件（精灵）

**部件**块列出对象的图片，每个部件一个小块：其 **Id**、**Image**（选择器或手动输入路径）、**Geometry**（`upright` 立于锚点上，`ground` 平铺于地面，`plane` 为竖直平面，`quad` 为自由四边形）、**Along**（用于 `plane`）、**Crop**（图片像素中的 x、y、w、h；留空为整张图片）、**偏移**（格中的 x、y）、**尺寸**（格中的 w、h）、**角点**（`quad` 的四个 `x, y, z` 点）以及**显示于**（某一投影或两者）。**添加部件**、**上移**、**下移**和**移除部件**用于调整顺序。该表显示对象自身的部件；通过 **Extends** 从父对象继承的部件，游戏会绘制，但表中暂时不列出。

## 占地与固体

**宽**和**高**（格）定义占地范围。其下的网格是**遮罩**：点击可在 `#`（阻挡行走）与 `.`（可通行）之间切换一个格。新的尺寸会将遮罩恢复为对象的固体设置。**标志**包含**阻挡行走**（按形状、是或否）、**隐藏**（不绘制、不阻挡、不可互动）、表面的**水**和**与相邻材质融合**，以及部件的**绘制顺序**。

## 锚点

锚点是游戏据以排序和放置对象的点。在任一预览上按住并拖动黄色标记：指针下的格子成为锚点，取其中心（数值以对象左上角格为原点的格数写入，例如 `1.5, 2.5`）。表单中的**锚点**字段保存相同的值，也可以手动输入。

## 互动

**互动**块设置玩家在对象上触发的内容：

- **触发**：`Use`（旁边按动作键）或 `Step`（踏上其所在的格）。
- **选择场景...** 打开所有已加载模组的场景脚本列表。场景和传送不能同时设置：选择其一会移除另一个。
- **选择地图...** 配合**列**、**行**和**到达时的朝向**，可设置传送到另一张地图的某一格。
- **脚本行**是命令，每行一条，触发时执行。
- **移除互动**移除整个块。

## 状态

状态在其条件成立期间改变对象：一个打开的箱子，一扇解锁的门。**状态**块列出它们，并提供**添加状态**、**移除状态**和**上移 / 下移**。每个状态有 **Id**、**条件**（例如 `self.open == 1`；条件成立的最后一个状态生效）、**Facing**、**隐藏**、**阻挡行走**、自己的部件和自己的互动。预览上方的**显示**选项可把预览切换到某个状态，从而看到游戏绘制的每个状态。

## 变体

变体是用于季节或外观的部分对象：冬季的树、损坏的门。**变体**列出它们；**变体名**和**添加变体**创建一个，**移除变体**删除所选的。精灵变体编辑自己的部件；表面或分段变体则指定图片。**显示**在预览中选择变体。

## 光源与路线

**主光源**为对象提供自身的光（以格计的半径，颜色中的alpha 为强度，以格计的位置）。**添加光源**添加更多带各自位置的光源。**沿路线移动**让对象沿固定路线行走：其**步骤**（逗号分隔：`up`、`down`、`left`、`right`、`random`、`toward`、`away`、`wait`、`face_up` … `face_right`）、**每步秒数**和**重复**。

## 其他模组的对象

**其他模组的条目**（默认勾选）列出模组依赖项的对象，并标注所有者：`↗ rpg`。所有者的文件从不被写入。编辑这类对象时，会在你的模组中写入补丁文件 `patches/rpg_object/<你的模组>.json`，只包含你改动的值。游戏使用所有者的对象，并在其上叠加你的补丁。

- **恢复为继承值**会移除你对该对象的补丁，游戏重新看到所有者的值。
- 对其他模组对象使用**复制**会生成一个带新 id 的自有对象，可随意修改。
- 删除其他模组的对象会在补丁中写入 `$delete` 条目。

## 预览

预览位于字段下方，显示游戏所见的所选对象，包括尚未保存的修改。**显示**可选择默认外观、变体或状态。投影选择器可并排显示**两者**，或仅**俯视**、仅**等轴测**。预览在一张小的样例地图上绘制对象，而不是世界地图。

## 使用对象

- 精灵或角色在 RPG 地图编辑器中放置：其调色板在**精灵**标签页列出精灵，在**角色**标签页列出角色。保存后的对象立即出现在那里。
- 带互动的精灵在玩家使用或踏上时，会启动其场景，或把玩家传送走。

## 暂缓事项

本版本未包含：

- 通过 **Extends** 继承的部件不在部件表中列出（游戏和预览会绘制它们）；
- 直接在预览上用画笔绘制占地范围（目前的编辑器是表单中的遮罩网格）；
- 表面预览中的相邻材质，以及精灵预览中的玩家角色；
- **Extends** 中父对象的缩略图；
- 创建对象子项的按钮：请手动设置 **Extends**。

## 出错时

1. **对象没有出现。** 它在另一个模组中，或列表被过滤：清空搜索，或为所有者的对象勾选**其他模组的条目**。
2. **预览只显示一种投影，或提示某投影未加载。** 该投影的渲染模组不在游戏中。
3. **修改在游戏中看不到。** 先保存（Ctrl+S）。只有已保存的文件才会进入游戏。
4. **PNG 导入被拒绝。** 消息会说明原因：不是 PNG、图片为空，或名称已存在。这种情况下不复制任何内容。
5. **其他模组的对象没有变化。** 它的文件不会被写入；你模组中的补丁携带了修改，**恢复为继承值**会将其移除。
